# Welcome to MCP-DSL

**MCP-DSL** is a domain-specific language designed for declaratively modeling AI workflows — particularly those involving interaction between models and evolving context. It bridges the gap between natural language prompts and auditable, reusable, protocol-driven AI execution.

---

## ✨ What Is It?

MCP-DSL is:

* A high-level language for orchestrating AI models and state
* A framework for building repeatable, traceable, and composable workflows
* A layer between ephemeral prompts and durable system logic
