🧩 Suggested Language Targets & Use Cases



| Language    | Reason to Include                                    | Output Format         |
|-------------|-------------------------------------------------------|------------------------|
| Python      | Most popular for ML and prototyping                   | Classes, functions     |
| Rust        | Strong typing, performance, embedded agents           | Structs + traits       |
| Go          | Backend microservices, minimalism                    | Structs + methods      |
| TypeScript  | Frontend agents, web-hosted model contexts            | Interfaces + modules   |
| Kotlin      | JVM + Android AI apps                                | Data classes + flows   |
| C++         | Robotics, embedded                                    | Headers + impl stubs   |
| Java        | Enterprise backends, JVM AI tools                     | Classes + POJOs        |
| Lua         | Game engines, embedded DSLs                          | Tables + functions     |
| Bash        | Workflow glue                                         | CLI stub generators    |
| Markdown    | For docs and learning                                 | Examples, signatures   |
| JSON Schema | To validate context structure                         | For use in tooling     |
